ESP-P4d

Fröling-Heizung (Lambdatronic S3200) über COM1 auslesen – Firmware für den Wemos S2 Mini direkt aus dem Browser installieren. Version …

1. Board in den Download-Modus

  1. Taste 0 (BOOT) gedrückt halten und das Board per USB einstecken (oder: 0 halten, RST kurz drücken), dann 0 loslassen.
  2. Der PC sieht jetzt einen Port „ESP32-S2“ (USB-ID 303A:0002).
Ohne Download-Modus erscheint der S2 Mini mit fremder oder ohne Firmware oft gar nicht als serieller Port – das ist normal.

2. Installieren

Dieser Browser kann kein Web Serial. Bitte Chrome, Edge oder Opera am Desktop verwenden (nicht Firefox, Safari, iPhone/iPad).
Web Serial geht nur über HTTPS – diese Seite direkt über GitHub Pages öffnen.

Port „ESP32-S2“ wählen. Beim ersten Mal „Gerät löschen“ anhaken.

Nach „Installation abgeschlossen“ das Board einmal ab- und wieder anstecken (oder RST drücken) – der S2 startet nach dem Flashen nicht von selbst.

3. Einrichten

  1. Mit dem Handy ins WLAN esp-p4d-setup (Passwort esp-p4d-setup) – die Seite öffnet sich meist von selbst, sonst http://192.168.4.1.
  2. Einstellungen (Benutzer admin, Passwort admin) → Netze suchen → WLAN wählen → Verbinden. Danach erreichbar unter http://esp-p4d.local.
  3. Einstellungs-Passwort sofort ändern.
  4. MAX3232 an COM1 des Kessels anschließen (siehe Verdrahtung).

Updates später ohne Flasher: Weboberfläche → Einstellungen → Firmware-Update mit der .bin aus den Releases.
